# SatelliteBlock

This repository contains the C++ codes and script for ``SatelliteBlock`` and ``ConstellationBlock`` to model the Satellite Constellation Design Problem (SCDP) [1,2] in [SMS++](https://smspp.gitlab.io/).

# Bibliography

[1] L. Mencarelli, J. Floquet, and F. Georges. Matheuristics approaches for the satellite constellation design problems. Optimization and Engineering, 2023.

[2] L. Mencarelli, J. Floquet, F. Georges, and D. Grenier. Mixed integer (non)linear approaches for the satellite constellation design problem. Optimization and Engineering, pages 1–22, 2022
